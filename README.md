# Weekly Wins Studio

A weekly team wins email editor with an optional OpenAI-powered vibe generator. Requires Node.js 22.13 or newer. There are no npm dependencies to install.

Run `npm start` and open http://127.0.0.1:5173. A plain static server can still run the editor, but generation requires the Node server.

To enable OpenAI, copy `.env.example` to `.env` if `.env` does not exist, and set `OPENAI_API_KEY` to your API key. The local server reads this file when you generate, so adding or changing a key does not require restarting it. You can optionally change `OPENAI_MODEL` (default: `gpt-4.1-mini`). Existing environment variables take precedence over the file. Do not put the key in chat or in `dist/`. `.env` files are ignored by Git and are never served to the browser. API requests use your OpenAI project’s billing.

1. Clear the clearly labeled sample wins, then add wins individually or paste team updates. Batch import supports `Team:` headings with one win per line and `Team: win` lines. Review the results before sending.
2. Choose a preset or describe your own vibe in The vibe tab. Generate a proposed edition, review it, then choose **Use this vibe**. OpenAI suggests a subject, introduction, headline, closing, colors, win headlines, an image/GIF idea, and an optional distinct original riddle after each team’s group of wins. Edit team riddles in The extras tab and optionally include their answers together at the end of the email. Team names, original win bodies, images, and fun facts are preserved. Generated headlines still require factual review. Theme switches preserve custom wording. Custom themes survive draft saving and JSON export/import.
3. Expand **Images / GIFs** in any win card. Drag and drop multiple files, click to choose files, or add direct HTTPS image links. Add descriptions and captions, reorder, remove, or download individual images. Photos fit within 1,072 × 1,600 pixels without upscaling, and opaque images are compressed as JPEG; transparent PNGs keep their transparency. GIFs and WebP files retain their original animation and bytes. Uploads are limited to 2 MB total per edition and 12 images per win, with hosted links available for larger animations. Each visual appears directly after its win, before its team’s riddle, and survives draft saving and AI vibe generation. Uploaded files stay in your browser and are excluded from OpenAI requests. HTML downloads embed uploads. Gmail copying uses insertion markers for uploaded files: download them from their cards and insert them directly in Gmail. Hosted HTTPS images are included in the formatted copy. The extras tab also supports an edition-wide image. Add a verified fun fact with a source, or trivia. The answer can optionally appear at the end.
4. Copy the formatted email, open Gmail, paste it into the message body, and copy the subject separately. Add recipients and review in Gmail before sending. Gmail plain-text mode must be off. Rendering and animated GIF behavior can differ by email client. If rich copying is unavailable, download HTML, open it in a browser, select and copy its rendered content.

Drafts save in this browser's local storage; they are not synced across devices. Download/load JSON drafts for backup or transfer. New edition clears the current content after confirmation. Generation sends your creative prompt, company/date, opening/closing, and active team wins to OpenAI using the Responses API with structured output and `store: false`. No request bodies or secrets are logged by this app. No Gmail connection, automatic Gmail draft creation, or email sending is implemented. Remote images and the interface's optional Google Fonts are requested from their hosts.

The Node server binds to loopback only and rejects cross-origin requests. It allows one generation at a time with a 60-second upstream timeout. It is intended for local use, not public hosting. The retained Sites manifest currently describes a static site; a hosted AI version would need a server-capable deployment, authentication, and a server-side key before publishing.

Run `npm test` for email generation, input/output validation, draft persistence, content preservation, OpenAI error handling, and local API route checks. These tests mock OpenAI responses and do not incur API charges. Run `node --check dist/app.js` and `node --check server.mjs` for syntax checks.

Official API references: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini).

The extras tab now includes **The weekly brain break**: generate a generic five-letter guessing puzzle and four Connections categories, review/edit the answers, preview both games, and export an immutable edition JSON. Browser progress and colored-square result sharing are supported. Add a published HTTPS or direct S3 website game URL to include the teaser and play link in Gmail; gameplay opens in a browser. Local-only cards are omitted from Gmail copy. See [direct static S3 hosting](infra/S3.md) for the current deployment path. The earlier CloudFormation stack remains optional. The editor and OpenAI key stay local.

For themed games, enter a **Five-letter word theme** and **Connections themes 1–4**, then choose **Generate themed puzzles**. The local OpenAI endpoint uses your existing configured model and sends only the five themes and edition date, with API storage disabled. It generates one five-letter answer and one category containing four distinct entries per Connections theme. Review category coherence and ambiguity in the answer editor. Invalid or failed generations preserve the existing edition. Themes save with drafts; changing theme fields while a request runs prevents stale output from applying. **Surprise me (generic)** still uses the curated bank without an AI call.
