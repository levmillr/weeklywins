# Direct static S3 hosting

Current hosting path: upload the game assets to an existing S3 static website. No Route 53, CloudFormation, CloudFront, server, or OpenAI key is required on the host. The five-letter game and Connections run entirely in the browser. Generation stays in the local editor.

Choose a bucket/account/region first. In the bucket, enable static website hosting with an index document (normally index.html) and make only the `weekly-wins-games/*` objects publicly readable. The uploader does not change bucket or account public-access settings, bucket policies, or website configuration. If account public-access controls prevent public websites, report that restriction before changing account settings.

Export the puzzle JSON from The extras. Copy the exact website endpoint from S3 → bucket → Properties → Static website hosting, then run:

```sh
node scripts/games-s3.mjs --profile YOUR_PROFILE --region us-east-1 --account YOUR_ACCOUNT_ID --bucket YOUR_BUCKET --website-url http://YOUR_BUCKET.s3-website-us-east-1.amazonaws.com/ --puzzle /absolute/path/to/exported-edition.json
```

The script checks the AWS account, bucket ownership, bucket region, and static website configuration. It uploads only four game files and the reviewed puzzle JSON under `weekly-wins-games/`. It preserves older editions and other bucket contents. It does not upload the editor, wins, images, .env, or API key. If access fails after upload, adjust only the intended game-prefix read policy using your account’s normal process; the uploader does not change permissions automatically.

Open the printed game URL to verify both games, then paste it into **Published game URL**. The email accepts HTTPS and direct HTTP S3 website URLs. S3 website endpoints support HTTP only; HTTPS requires an additional hosting layer. See [AWS website endpoint documentation](https://docs.aws.amazon.com/AmazonS3/latest/userguide/WebsiteEndpoints.html). Game-result copying uses a fallback for HTTP pages. Puzzle answers are inspectable, as expected for this casual static game.

When you want to retire a hosted edition, remove its exact JSON object after confirming the old link can stop working. Remove the `weekly-wins-games/` prefix only when all its editions can be retired. Do not delete a shared bucket. The earlier CloudFormation files are optional and unused by this S3 uploader; no stack or DNS changes occur.
